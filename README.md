# KAI (AI Desktop Assistant)

KAI is an AI-powered desktop assistant built with Tauri, React, Typescript, and Rust. It features advanced capabilities including voice activity detection, screen capture, audio processing, and browser automation.

## Tech Stack
- **Frontend**: React, TypeScript, Vite
- **Backend**: Rust (Tauri)
- **Integrations**: Python scripts (Calendar, Email)

## Features
- Voice Activity Detection (VAD)
- Audio capture and processing
- Screen capture
- Browser automation
- Desktop integrations

## Getting Started

### Prerequisites
- Node.js
- Rust (latest stable)
- Python 3

### Installation

1. Install Node dependencies:
   ```bash
   npm install
   ```

2. Run the application in development mode:
   ```bash
   npm run tauri dev
   ```

### Building for Production

```bash
npm run tauri build
```
